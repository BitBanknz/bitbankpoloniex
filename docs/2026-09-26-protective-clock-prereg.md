# Fixed ablation: key protective exits to the observed hour

The preceding minute-exit experiment combined two changes: actual observation
time in protective order IDs and additional reductions within an hour. All
twelve changed historical accounts first diverged after a midnight protective
sell used the forecast's 01:00 key, preventing a later 01:00 sale. Three unique
underlying ZEC episodes produced those twelve comparisons. This is discovery
evidence, and the historical fixture remains reused research data.

Test one new arm that changes only the protective decision clock. Starting from
the authenticated guarded release, for a currently stopped, non-imported holding,
pass the actual observed UTC hour to the existing sell decision. Keep the normal
empty suffix and the existing one-successful-sell-per-symbol-per-hour limit.
Ordinary rotation/funding exits and imported allocations keep their old rules.
No minute-frequency exits, new forecast, altered sizing, augmentation, or tuning.
Use a private flag that defaults off and rejects live mode and fallback mode.

Before inspecting this arm's outcomes, freeze the following comparisons:

- The same nine historical configurations and 45 account windows: continuous,
  28-day and 56-day resets, all retained partial tails, 30/40/60-bps fees per side.
  The budget is 495 USDT, cap 49 USDT per order, three slots, 40% cash reserve,
  twelve orders/day, 120-hour cooldown and unchanged 25%/8% account halt bands.
- Reproduce all default-off historical reports and ledgers exactly against the
  guarded release, and independently reconstruct every new arm's account.
- Compare clock-only against both the guarded control and the sealed minute arm.
  Report all PnL/drawdown changes and any concentration in the three discovery
  episodes; do not select windows or fees after seeing results.
- Replay all three guarded control fee accounts on public prefix 78–3297 with
  each arm's own continuing state. This known no-stop prefix is a compatibility
  check, not new performance evidence.
- Native and race checks for midnight-to-execution-hour reductions, forecast
  loss/recovery within an hour, duplicate calls and process restarts, hour/day
  boundaries, no extra minute sells, ordinary and imported exits, quote failures,
  daily caps, risk halts, partial valuation, cooldown, and below-stop buy rejection.
  All fixture prior-cycle, equity, holding-entry and fill times must be causal.

Use the existing isolated public-loopback driver and the unchanged financial
reference apart from protective decision-clock reconstruction. Require native
suite, race and vet, preserve failures and use the same financial tolerances.

Historical hourly prices and synthetic depth cannot establish real minute fills,
intraminute drawdown or liquidity replenishment. A historical improvement here
does not create an independent holdout or establish the owner's 35% rolling
28-calendar-day / 40% full-window risk requirements. Separate a clock defect
reproduction from performance evidence. No live activation or changes to ongoing
paper studies are part of this experiment.
